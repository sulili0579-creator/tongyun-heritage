## 三、网站特点

1. **长期可访问**：纯静态架构，不受数据库、服务器程序限制，可整体拷贝归档。
2. **移动端友好**：响应式布局，手机端可流畅浏览全文、地图与表格。
3. **内容易更新**：所有文字、编号、图片路径集中存放，改一个文件即可全站更新。
4. **可移交**：项目结束后可移交会泽县文化馆，或持续提供独立访问链接。

## 四、使用与维护

### 普通访问
直接用浏览器打开访问地址即可，无需安装任何软件。

### 内容更新（管理员）
1. 修改本地文件（内容数据集中在 `js/data.js`、`js/library-data.js`）
2. 提交并推送：
   ```bash
   git add -A && git commit -m "更新说明" && git push
   ```
3. 推送后 1–2 分钟线上自动更新

### 故障排查与安全保障
详见随站交付的《网络维护手册》（`docs/网络维护手册.md`）。
