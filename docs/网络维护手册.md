# 铜运古道非遗文化网站 — 网络维护手册

面向：会泽县文化馆技术人员 / 项目组后续维护人员  
站点类型：**纯静态网站**（HTML/CSS/JS），无数据库、无后端程序。

---

## 1. 日常操作

### 1.1 目录结构

```
tongyun-heritage/
├── index.html              # 唯一主页面（单页站点）
├── css/style.css           # 样式
├── js/
│   ├── data.js             # ★ 内容数据（增删改主要改这里）
│   └── main.js             # 交互与地图逻辑
├── assets/
│   ├── images/             # 图片（jpg/png/webp）
│   ├── pdf/                # 调研报告 PDF
│   ├── audio/              # 口述录音 mp3/ogg
│   └── video/              # 纪录片、短视频 mp4
└── docs/
    └── 网络维护手册.md      # 本文件
```

### 1.2 更新文字与点位（最常用）

1. 用记事本 / VS Code 打开 `js/data.js`。
2. 按注释修改：
   - `oralHistories`：口述史选段、录音路径
   - `gallery`：图库标题、分类、图片路径（`road`/`craft`/`hall`）
   - `videos`：视频路径或 B 站 `bvid`
   - `mapPois`：地图点位名称、经纬度、简介、配图
   - `team` / `moments`：成员与花絮
3. 保存后 **强制刷新** 浏览器（Ctrl+F5）查看效果。
4. 无需编译、无需重启服务器（静态托管下上传覆盖即可）。

### 1.3 替换 / 新增媒体文件

| 类型 | 目录 | 建议格式 | 注意 |
|------|------|----------|------|
| 报告 | `assets/pdf/` | PDF | 文件名与 `index.html` 中下载链接一致，或同步改链接 |
| 图片 | `assets/images/` | JPG/WebP，单张建议 &lt; 1MB | 与 `data.js` 中 `src` 一致 |
| 录音 | `assets/audio/` | MP3 | 采访需已获授权 |
| 视频 | `assets/video/` | MP4（H.264） | 大文件可改用 B 站嵌入 |

**报告下载链接位置：** `index.html` 中「完整报告下载」按钮的 `href`。

### 1.4 修改地图点位坐标

1. 在 [OpenStreetMap](https://www.openstreetmap.org) 或手机地图中找到目标位置。
2. 记录 **纬度 lat、经度 lng**（小数点后 4–5 位即可）。
3. 写入 `data.js` → `mapPois` 对应项。
4. `type` 可选：`hall`（会馆）、`relic`（遗存）、`workshop`（工坊）、`other`。

### 1.5 视频改为 B 站嵌入

在 `data.js` 中将该条改为：

```js
{
  id: "v1",
  title: "实践纪录片",
  desc: "……",
  type: "bilibili",
  bvid: "BVxxxxxxxxxxxx"
}
```

### 1.6 本地预览

在项目根目录执行（任选其一）：

```bash
# Python 3
python3 -m http.server 8080

# Node.js
npx --yes serve -p 8080
```

浏览器打开：`http://127.0.0.1:8080`

> 说明：直接双击打开 `index.html` 时，部分浏览器可能限制地图瓦片或本地媒体，**推荐用本地服务器预览**。

### 1.7 上线与移交

可选方式：

1. **单位已有网站空间 / 对象存储静态托管**：上传整个 `tongyun-heritage` 文件夹。
2. **GitHub Pages / 云静态网站托管**：绑定自定义域名后提供独立访问链接。
3. **内网 U 盘 / 文化馆电脑**：拷贝文件夹，用本地服务器或内网 IIS/Nginx 指向该目录。

移交清单建议：

- [ ] 报告 PDF 定稿与授权说明

## 2. 故障排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 页面样式乱、无布局 | `css/style.css` 路径错误或未上传 | 检查相对路径；保证目录结构完整 |
| 地图灰屏 / 不显示 | 无外网；或 Leaflet CDN 被拦 | 确认可访问 `unpkg.com` 与 `tile.openstreetmap.org`；内网需改为离线瓦片方案 |
| 地图点不准 | 经纬度填反或用了百度坐标 | OSM 使用 **WGS84**；不要直接填百度/高德坐标（需转换） |
| 图片不显示，只有色块标题 | 文件不存在或文件名不一致 | 核对 `assets/images/` 与 `data.js` 路径（区分大小写） |
| 音频/视频无法播放 | 格式不支持或路径错误 | 转为 MP3/H.264 MP4；用本地服务器访问 |
| PDF 下载 404 | 尚未上传或文件名不符 | 将 PDF 放到 `assets/pdf/` 并统一文件名 |
| 手机菜单打不开 | `main.js` 未加载 | 检查 `js/main.js` 是否上传 |
| 修改 data.js 无变化 | 浏览器缓存 | Ctrl+F5 强刷；托管平台可开缓存刷新 |

### 2.1 浏览器控制台

按 F12 → Console，红色报错可协助定位（缺文件、JS 语法错误等）。  
`data.js` 若多写/少写逗号、括号，会导致整页数据不渲染。

### 2.2 地图 CDN 备用说明

当前使用：

- CSS/JS：`https://unpkg.com/leaflet@1.9.4/...`
- 瓦片：`https://{s}.tile.openstreetmap.org/...`

若需国产地图（百度/高德），须申请 API Key，并改写 `main.js` 地图初始化部分，同时遵守厂商服务条款；**长期归档更推荐 OSM 开源方案**，避免 Key 过期导致空白。

## 3. 安全保障事项

1. **无后台、无数据库**：不收集用户密码；勿在页面中嵌入采集身份证号等敏感表单。
2. **不要把密钥写进仓库**：若改用高德/百度，API Key 应设域名白名单与配额，并限制引用。
3. **版权与肖像权**：上线前确认报告、照片、录音、视频已获项目组及受访者授权；页脚可补充“仅供文化公益展示”。
4. **文件上传安全**（若文化馆有统一上传入口）：仅允许管理员更新静态文件，禁止上传可执行脚本（.php/.jsp 等）。
5. **HTTPS**：公网访问务必启用 HTTPS，防止篡改与中间人注入。
6. **备份**：每次大更新前打包整个站点目录，保留至少 2 份（本地 + 异地），建议命名：`tongyun-heritage-YYYYMMDD.zip`。
7. **内容审核**：外链（如 B 站）变更时检查是否仍可访问、是否适宜公开展示。
8. **依赖精简**：除 Leaflet CDN 外无构建工具依赖；若断网展陈，需提前下载 Leaflet 与离线地图方案。
