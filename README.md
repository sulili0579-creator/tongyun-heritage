# 铜运古道非遗文化 · 数字化展示平台

静态专题网站（1 个站点），用于项目数字化成果的长期在线访问与检索。

## 栏目对照

| 要求 | 实现 |
|------|------|
| 调研报告摘要 + PDF 下载 | 首页「调研报告」+ `assets/pdf/` |
| 传承人口述史 | 传承人卡片 + 访谈 PDF 详情页 |
| 影像档案图库 | 分类筛选 + 灯箱 |
| 实践纪录片 | 本地 MP4 + 详情页播放 |
| 移动端适配 | 响应式 CSS |
| 维护手册 | `docs/网络维护手册.md` |

## 快速预览

```bash
cd tongyun-heritage
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

## 更新内容

编辑 `js/data.js`，并将媒体文件放入 `assets/` 对应目录。详见维护手册。

## 移交

整个文件夹拷贝即可部署；无数据库、无构建步骤。
